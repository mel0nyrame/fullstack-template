# 学习了很多奇奇怪怪的属性
具体内容参考如下
html属性
每个标签都可以有多个属性用于描述这个标签/元素的特征和行为
1.基本语法
<开始标签 属性名=“属性值”>
属性名 用于标识这个属性的
属性值 定义这个属性的值
属性值一般用于定义这个引号将其括起来可以是单引号或者双引号

2.每个html可以具备不同的属性

3.属性名称不区分大小写 属性值对大小写敏感

4.常见通用html属性（css常用）
class 定义类名（样式文件的类）
id 定义元素唯一的 id
style 规定元素的行内样式

5.重要小标签
	⁃	a标签 
创建完成后自动弹出href属性
a标签常用于创造链接 用于链接到其他网页或者位置
	⁃	href
这个属性很重要 href=“”
定义了链接到的目标 可以是其他网页的url文件路径 电子邮箱地址 手机号等等

	⁃	target
第二重要的属性
target用于定义链接的打开方式
注意注意 target放在双引号后 这个>符号前
输入后按tab 我们就可以选择四种打开方式
想知道四种方式的含义可以把光标点到target会有解释
_self：默认值，在当前标签页或框架中打开。
_blank：通常在新的标签页或窗口中打开。
_parent：在当前框架的父级框架中打开（若无父框架，行为同 _self）。
_top：在整个浏览器窗口中打开，跳出所有框架。‌￼

	⁃	换行标签br
在一个标签后头输入br➕tab 就会使语句出现在第二行

	⁃	hr创建水平分割线
	⁃	img标签
输入img标签后 会自带两个属性 src（定义图像的路径或者url）可以是相对路径或者绝对路径也可以是url
要用到的图片可以直接拖进去
或者在网上随便找一张图片把图片链接复制进去
alt定义图像替代文本 例如打不开照片里面输入文本 该图片无法显示
tips：要是想要更改图片的宽高
则需要这两个属性
这两个要在alt的引号后面
width 和 height并在对应地方输入数值
更改图片大小
