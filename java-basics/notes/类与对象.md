# Java 类与对象

## 类与对象

- 类：对一类事物的描述（抽象群体）
- 对象：某一类事物实际存在的每个个体（实例个体）
- 面向对象编程：先定义一个类，再用它创建许多这个类的实例对象

## 类的定义和创建对象

- 类名用大驼峰命名法（每个单词首字母大写），变量名和方法名用小驼峰（首字母小写）
- 把想要描述的属性作为成员变量加到类里面
- `new 类名();` 用来创建这个类的对象。new 后面调用的其实是构造方法，自己不写的话编译器会自动给一个无参构造

```java
public class Student {
    String name;
    int age;
}
```

## 对象的使用

- 用变量来指代某个对象：`类名 变量名 = new 类名();`
- 引用类型的变量存的是对象的引用，不是对象本身
- 访问属性用 `.` 运算符：`变量名.属性名 = 值;`

```java
Student s = new Student();
s.name = "张三";
s.age = 18;
```

- 不同对象的属性是分开独立存放的，改一个不影响另一个

```java
Student a = new Student();
Student b = new Student();
a.age = 18;
System.out.println(b.age);   // 0，两个对象的属性互不影响
```

- 引用变量也可以不指向任何对象：`Student s = null;`。这样能正常编译，但拿它去访问属性或调用方法，运行时会报 NullPointerException
- 创建对象时成员变量有默认值：整数是 0，小数是 0.0，boolean 是 false，引用类型是 null。局部变量没有默认值，用之前必须先赋值

## 方法的创建和使用

方法类似 Python 和 C 语言里的函数，必须写在类里面。调用格式：`变量名.方法名(实参);`

```java
public class Calculator {
    int sum(int a, int b) {
        int c = a + b;
        return c;          // 或者直接 return a + b;
    }

    void printSum(int a, int b) {
        System.out.println(a + b);
    }
}
```

```java
Calculator c = new Calculator();
int r = c.sum(3, 5);   // r = 8
c.printSum(3, 5);      // 输出 8
```

- `void`：只完成任务，没有返回值。可以写 `return;` 提前结束，但不能 return 值
- `int` 等：要返回对应类型的值，方法体里必须用 `return` 返回
- 方法定义时写的参数叫形式参数（形参），调用时传进去的叫实际参数（实参），多个参数用逗号隔开
- `return` 后面不能再写代码，否则是不可达语句，编译不通过
- 有返回值的方法，所有可能的执行路径都要有返回值。if/else 两边都 return 可以；只写了 if 没写 else，就要在后面补一个兜底的 return，不然编译报 missing return statement
- `return` 是结束整个方法；`break` 只结束当前这一层循环，循环后面的代码还会继续走；`continue` 是结束本次循环，进入下一次
- 基本数据类型：方法里的操作不会改变外面的实参，参数传递只是值传递
- 引用类型：传进去的是引用的副本，还是指向同一个对象，所以在方法里改对象的属性，外面的对象会跟着变；但如果让参数重新指向一个新对象，外面的变量还是指向原来的对象

## this 关键字

- `this` 代表当前对象本身，最常用的是区分同名的成员变量和形参：`this.name = name;`
- 也可以 `this.方法名()` 调用本类的其他方法
- `this(参数)` 可以在构造方法第一行调用本类的另一个构造方法
- `this` 不能用在 static 方法里
