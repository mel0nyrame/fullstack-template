# 学习计划

## 1. 我理解这个系统要解决什么问题

科研团队有一笔经费。成员想买设备或材料，要先提申请，老师审批，财务再登记实际花了多少。系统要记清楚：谁申请了什么、批了多少钱、实际花了多少，以及项目还剩多少钱可用。

钱分三种状态：可用是还能申请的钱，冻结是已经申请但还没结算的钱，已使用是财务登记的实际花费。每一步都要满足"总额 = 可用 + 冻结 + 已使用"，而且三项都不能为负数。

一个人可以参加多个项目，但一张申请只属于一个项目。系统不连接银行，也不做真实支付。

这个系统最重要的是钱不能算错，否则失去了它作为财务系统的意义。

## 3. 我准备先完成哪个小目标

先不碰框架，用普通 Java 类写出"成员"和"申请"，在 main 方法里模拟一次完整过程：创建成员 → 提交申请 → 经费冻结。跑起来能打印出三个金额的变化，这一步就算完成。

这一步能先弄懂经费怎么变，再考虑存进数据库、提供接口、做页面。

前端准备用 Vue 3 + JavaScript，不用 TypeScript，因为时间比较紧，TS 的类型系统要额外学一套写法。

另外，我实际能投入的时间比文档写的六周要少，所以先把核心流程做出来，05 的进阶需求待定。
